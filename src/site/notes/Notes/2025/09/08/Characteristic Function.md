# Characteristic Function

## I. Introduction

In probability theory and statistics, the **Characteristic Function (CF)** of a real-valued random variable is a fundamental tool for analyzing its distribution. It is defined as the expected value of $e^{itX}$, where $i$ is the imaginary unit and $t$ is a real number. The characteristic function can be understood as the **Fourier transform** of the probability density function (or probability mass function).

Its paramount significance lies in a key advantage over the related [[Notes/2025/09/08/Moment-Generating Function\|Moment-Generating Function]]: **the characteristic function exists for *every* random variable**. This universal existence, combined with a one-to-one correspondence with the probability distribution, makes it an exceptionally powerful and robust tool for theoretical work, particularly for proving limit theorems like the Central Limit Theorem.

## II. Formal Definition

Let $X$ be a random variable. Its **Characteristic Function**, denoted by $\phi_X(t)$, is a function $\phi_X: \mathbb{R} \to \mathbb{C}$ defined as:
$$
\phi_X(t) = E[e^{itX}]
$$
Using Euler's formula, $e^{i\theta} = \cos(\theta) + i\sin(\theta)$, this can be written as:
$$
\phi_X(t) = E[\cos(tX) + i\sin(tX)] = E[\cos(tX)] + iE[\sin(tX)]
$$
The definition is specified based on the nature of the random variable:

-   **For a discrete random variable** with probability mass function $p(x_k)$:
    $$
    \phi_X(t) = \sum_{k} e^{itx_k} p(x_k)
    $$
-   **For a continuous random variable** with probability density function $f(x)$:
    $$
    \phi_X(t) = \int_{-\infty}^{\infty} e^{itx} f(x) \,dx
    $$
This integral form makes it clear that the characteristic function is the Fourier transform of the probability density function (the specific normalization constant may vary depending on the convention used for the Fourier transform).

## III. Core Properties

The characteristic function possesses a rich set of properties that make it indispensable in probability theory.

### 1. Universal Existence
The characteristic function $\phi_X(t)$ exists for any random variable $X$. This is because the function being integrated or summed, $e^{itx}$, is bounded. Specifically, its magnitude is always one:
$$
|e^{itx}| = |\cos(tx) + i\sin(tx)| = \sqrt{\cos^2(tx) + \sin^2(tx)} = 1
$$
Therefore, the integral or sum defining the expectation is always convergent.

### 2. Uniqueness and the Inversion Theorem
There is a one-to-one correspondence between probability distributions and characteristic functions. This is formalized by **Lévy's Inversion Theorem**, which states that the probability density function can be recovered from the characteristic function via the inverse Fourier transform. If $\phi_X(t)$ is integrable, the density function $f(x)$ can be found by:
$$
f(x) = \frac{1}{2\pi} \int_{-\infty}^{\infty} e^{-itx} \phi_X(t) \,dt
$$
This uniqueness property allows us to identify a distribution by simply calculating its characteristic function.

### 3. Generating Moments
If the $n$-th moment of $X$ exists, the characteristic function is $n$ times differentiable, and the moments can be generated by differentiation at $t=0$:
$$
E[X^n] = \frac{1}{i^n} \frac{d^n}{dt^n} \phi_X(t) \bigg|_{t=0}
$$
-   **First Moment (Mean)**: $E[X] = \frac{1}{i} \phi'_X(0)$
-   **Second Moment**: $E[X^2] = \frac{1}{i^2} \phi''_X(0) = -\phi''_X(0)$

### 4. Sums of Independent Random Variables
If $X_1, X_2, \dots, X_n$ are independent random variables, the characteristic function of their sum $S_n = X_1 + \dots + X_n$ is the **product** of their individual characteristic functions:
$$
\phi_{S_n}(t) = \phi_{X_1}(t) \cdot \phi_{X_2}(t) \cdots \phi_{X_n}(t)
$$
This property transforms the complex operation of convolution into simple multiplication.

### 5. Affine Transformations
For a random variable $Y = aX + b$ with constants $a$ and $b$, its characteristic function is:
$$
\phi_Y(t) = E[e^{it(aX+b)}] = e^{itb} E[e^{i(at)X}] = e^{itb} \phi_X(at)
$$

## IV. Example: The Normal Distribution

Let $Z \sim \mathcal{N}(0, 1)$ be a standard normal random variable. Its characteristic function is:
$$
\phi_Z(t) = e^{-t^2/2}
$$
Now, consider a general normal random variable $X \sim \mathcal{N}(\mu, \sigma^2)$. We can represent $X$ as an affine transformation of $Z$: $X = \sigma Z + \mu$. Using the property from section III.5:
$$
\phi_X(t) = \phi_{\sigma Z + \mu}(t) = e^{it\mu} \phi_Z(\sigma t)
$$
Substituting the known CF for $Z$:
$$
\phi_X(t) = e^{it\mu} e^{-(\sigma t)^2/2} = \exp\left(it\mu - \frac{1}{2}\sigma^2 t^2\right)
$$
This is the characteristic function for any normally distributed random variable.

## V. Comparison with the Moment-Generating Function

| Feature | **Characteristic Function (CF)** | **Moment-Generating Function (MGF)** |
| :--- | :--- | :--- |
| **Definition** | $E[e^{itX}]$ | $E[e^{tX}]$ |
| **Existence** | **Always exists** for any random variable. | May not exist (e.g., for heavy-tailed distributions). |
| **Domain** | Defined for all real $t \in \mathbb{R}$. | Defined for $t$ in an open interval containing 0. |
| **Nature** | Complex-valued function (Fourier Transform). | Real-valued function (Laplace Transform). |
| **Inversion** | Yes, the distribution can be recovered via an inversion formula. | Yes, but the inversion is more complex (Bromwich integral). |

## VI. Conclusion

The Characteristic Function is a cornerstone of modern probability theory. Its guaranteed existence for all distributions makes it a more general and powerful tool than the Moment-Generating Function. By mapping probability distributions into the frequency domain through the Fourier transform, it provides a unique signature for each distribution, simplifies the analysis of sums of independent variables, and serves as the primary analytical instrument for proving fundamental results like the Central Limit Theorem. Its properties underscore the deep and fruitful connection between probability theory and Fourier analysis.
